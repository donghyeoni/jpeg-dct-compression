# Data

The experiments expect the standard **Lena** test image at `data/lena.bmp`
(512x512, color).

This image is **not included** in the repository. Please supply your own copy
and place it here as `lena.bmp`, or pass a different path via `--image`.

See the "Dataset" section of the top-level [README](../README.md) for details
and redistribution caveats.
